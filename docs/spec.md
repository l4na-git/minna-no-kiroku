# 現行仕様

`product.md` の体験を実現する現行版の仕様。技術面は `tech.md`、画面は `design.md`、今後の構想は `roadmap.md` を参照。

## 目的

「気づきを気軽に書いて、親族と共有して、あとで見返せる」体験を提供する。AI は使わず、親族が入力した記録をそのまま保存・共有する。

## 含めるもの

1. ログイン: Cloudflare Access で許可された人だけが利用する。アプリ側にログイン画面は作らない。
2. 家族の共有スペース: 1つの設置先は1つの共有スペースとし、アクセスを許可された全員が、過去の記録を含むすべての記録を見られる。利用者の追加・アクセス停止は運用者がCloudflare Accessで行う。
3. 気づきの記録: 自然な文章、「いつあったことか」の日付と時間帯、カテゴリを入力して保存する。記録した日時は自動で入る。
4. 一覧とまとめ: 記録を出来事の日付ごとに一覧する。誰が書いたかとカテゴリも分かる。期間で絞り込み、新しい順・古い順を切り替えられる。月別・カテゴリ別の件数を、解釈を加えずに見られる。印刷または PDF にできる。
5. 設定: 自分の表示名を変更できる。ログアウトできる。

## 含めないもの

- AI による整形、要約、傾向の分析
- 通知、画像・音声の添付
- グループの作成・切り替え・所属管理、アプリ内の招待機能
- 記録の対象者を選んで区別する機能
- 本人向けの画面、アカウントの削除、権限の細分化

## 記録の日時・カテゴリ

- 記録した日時（`created_at`）は、保存したときにシステムが自動で入れる。利用者は変更できない。
- 「いつあったことか」は、日付で入力する必須項目にする。初期値は記録する日で、過去の日付を選べる。朝・昼・夕方・夜のおおよその時間帯は任意で選べる。正確な時刻は持たない。
- 一覧の並び順、日付の見出し、期間の絞り込みは、出来事の日付にする。記録した日時は詳細で確認できる。
- カテゴリは必須で、初期カテゴリの `物忘れ`、`思い込み`、`その他` から 1 つ選ぶ。必要なら、許可された利用者が新しいカテゴリを追加できる。カテゴリは共有スペースで共有し、評価や診断を表さない。
- 本文、出来事の日付・時間帯、カテゴリは、書いた本人が編集できる。編集した記録には「編集済み」と表示する。記録した日時は変わらない。
- 複数の画面や端末で同じ記録を編集した場合、先に保存された変更を古い画面から黙って上書きしない。競合時は書きかけを保持し、最新の記録を確認してから編集し直す。
- 記録した日時は、設定したタイムゾーン（既定は `Asia/Tokyo`）で表示する。

## 一覧の仕様

記録を読み返す画面と、病院などで説明するための画面は、同じ一覧にする。既定は直近 1 か月・新しい順とし、期間は直近 1 週間・1 か月・3 か月・すべて、または日付を指定できる。並び順は新しい順と古い順を切り替えられる。

一覧にはカテゴリ、書いた人、本文を出す。本文は 3 行で省略し、タップで詳細を開く。「印刷 / PDFにする」は、画面に出ている期間と並び順のまま印刷する。印刷では本文を省略せず、アプリ名・期間・件数・並び順・出力日を入れる。

「増えている」「注意」などの解釈、点数、予測は出さない。月別・カテゴリ別の件数を、事実として示す棒グラフと数値は出せる。

## 設定と権限

- 表示名は家族に表示され、変更すると過去の記録にも反映される。メールアドレスは表示のみで変更できない。
- ログアウトは Cloudflare Access のログアウト（`/cdn-cgi/access/logout`）を呼ぶ。パスワードの設定はない。
- アクセスを許可された利用者は、共有スペースのすべての記録とカテゴリを見られる。新しい利用者も過去の記録を見られる。
- 記録を編集・削除できるのは、書いた本人だけ。他の親族の記録は編集も削除もできない。
- Access の許可を取り消した後も、その人が書いた記録は残る。アクセス停止とセッション失効は運用者が Cloudflare 側で行う。

## 画面

| 画面 | 内容 |
|---|---|
| 一覧 | 出来事の日付ごとに、カテゴリ・書いた人・本文を出す。期間の絞り込み、新しい順・古い順の切り替え、印刷 / PDF |
| まとめ | 3 か月ずつのカテゴリ別件数を積み上げ棒グラフで出す。別に選んだ 1 か月のカテゴリ別件数を横棒グラフで比べ、先月・翌月に切り替えられる。解釈・評価・予測は出さない |
| 記録の入力 | いつあったことか（日付・時間帯）、カテゴリ、本文の入力と保存ボタン |
| 記録の詳細・編集 | 出来事の日付・時間帯・カテゴリ・本文の編集、削除（本人のみ） |
| 設定 | 表示名の変更、メールアドレスの確認、ログアウト |

## 受け入れ条件

- Accessで許可された親族は、共有スペースの全記録を見られる。未許可・未認証の利用者は、URLを直接指定しても読めない。
- 記録を保存でき、記録した日時が自動で入る。出来事の日付とカテゴリを選ばないと保存できない。時間帯は任意で選べる。
- 本文が空のときは保存できず、自分の記録だけを編集・削除できる。編集した記録には「編集済み」と表示する。
- 一覧で期間の絞り込みと新しい順 / 古い順の切り替えができ、印刷では本文を省略せず全文を出す。
- まとめでは月別・カテゴリ別の件数を表示するが、評価・警告・予測は出さない。
- 表示名を変えると過去の記録の名前も変わり、ログアウトできる。
